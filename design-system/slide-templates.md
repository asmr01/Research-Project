# Slide templates

Nine slide archetypes cover the whole reference deck. Each is built from the
[components](./components.md) on the shared [grid](./foundations.md#grid--layout). Pick the
archetype that fits the job; don't invent new frames.

The template file itself ships these starter layouts:
`Title Slide · Divider Slide · Title and Content · Title and Two Content · Table Example ·
Two Content + Column Chart · Blank Full-Screen Visual · Thank you.`

---

## T1 · Cover

The opening slide.

- Title 48 pt (two lines max), subtitle below, date line.
- Right-side gradient overlay (`#0067A8` → white) or the three-peaks motif bleeding off a corner.
- White knockout text if over a photo/gradient; indigo if on white.
- **No** eyebrow, rule, sources, or page number.

> `Cell & Gene Therapy Manufacturing` / `Initial Research and Assessment` / `June 2026`

## T2 · Executive summary + Contents

Slide 2, always. The argument in miniature.

- Eyebrow `EXECUTIVE SUMMARY`.
- 4–6 **bold takeaway sentences**, each with a supporting clause.
- A `CONTENTS` list on the side mirroring the section numbers.
- This is the only slide allowed to be text-dense — it is a map, not a page to linger on.

## T3 · Section content (the workhorse)

~70% of the deck. The default `eyebrow → headline → rule → 2-col cards` frame.

- Eyebrow `NN · SECTION NAME`.
- Takeaway headline (20 pt indigo).
- Cyan rule.
- 4–6 feature/benefit cards in a 2-column grid.
- Sources footer + page number.

> `01 · WHY MANUFACTURE` — *AMCs are interested in manufacturing's convergence of research,
> speed, and economics…* → six benefit cards.

## T4 · Ladder / tiers

A ranked progression down the slide.

- Same header stack.
- Capability-ladder component: numbered rows, each with a right-side status pill and alternating
  band fills.
- A short Ink-Muted intro line can sit between the rule and the first rung.

> `04 · DEFINITION` — the 5-rung delivery-only → manufacturer → frontier ladder.

## T5 · Comparison axes

Two or three tradeoff pairs stacked.

- Header stack, then 2–3 "vs" pairs, each a labeled pole with a one-line gloss.
- Optionally pair with Term—gloss definitions above the axes.

> `02 · WHAT IT IS` — Vectors vs Cells, then the three axes (Autologous vs Allogeneic, etc.).

## T6 · Landscape table

The full-width "who does what" scan.

- Header stack, then a full-width data table with a shaded "our system" row and an 8 pt legend.
- Keep cells to fragments; push detail into the case studies that follow.

> `05 · WHO MANUFACTURES TODAY` — ~12 AMCs × {Type, In-house GMP, Makes, Designation}.

## T7 · Case studies

Deep dives, run as a numbered set.

- Eyebrow `CASE STUDIES · N OF M`.
- Descriptive headline naming the group ("The pioneers — Penn & CHOP").
- Two case-study cards side by side, each with History / People / Tech / Funding / Results rows.

## T8 · Options / recommendation

The decision slide.

- Eyebrow `NN · RECOMMENDATION & NEXT STEPS`.
- A "state of play" line, then 4 lettered options (Hold / Buy / Build / Partner), each with a
  `Diligence — Validate:` next-step line.

> `09 · RECOMMENDATION & NEXT STEPS` — Options A–D.

## T9 · Sources & method

Closing reference slide.

- Two-column list of every source: name (Bold) + full URL beneath.
- No page-number required; this is the appendix.

### Choosing a template

| If the slide's job is to… | Use |
|---|---|
| Open the deck | T1 Cover |
| State the whole argument up front | T2 Exec summary |
| Make 4–6 parallel points | T3 Section content |
| Show a maturity progression / tiers | T4 Ladder |
| Contrast options along axes | T5 Comparison |
| Scan many players at once | T6 Table |
| Profile specific organizations | T7 Case studies |
| Recommend a path | T8 Options |
| Cite everything | T9 Sources |

Every template keeps the same header stack and footer. The frame is constant; only the content
band changes. That consistency *is* the design system.
